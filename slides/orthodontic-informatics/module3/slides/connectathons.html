Connectathons: vendors test together

Teams bring their software and test it with other vendors.

IHE provides a shared framework for testing interoperability.

39–49 · Shape and test exchange

  • Connectathons: vendors test whether their software exchanges information with other vendors’ systems at organized, supervised events.
  • Shared framework: IHE (Integrating the Healthcare Enterprise) defines profiles—guidance for using existing standards in a clinical workflow—and provides test tools and events.
  • Improve the software: teams use test feedback to find and fix exchange problems; vendors still implement the software themselves.
  • Photographs: existing course images show IHE North America and IHE Europe 2022; they illustrate collaborative testing, not a particular product’s result.
