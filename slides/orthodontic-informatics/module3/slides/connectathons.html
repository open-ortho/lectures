Connectathons: test with other systems

Structured, supervised exchange tests
for selected roles and defined use cases.

IHE publishes test results; ask what the participating product actually tested.

Use the existing IHE North America photograph as an illustration of the community testing setting, not evidence for a particular current product. At an IHE Connectathon participating implementations exchange with other implementations under defined tests for selected IHE actors, meaning system roles, and profiles, meaning specified interoperability use cases. Published results can provide bounded evidence about those tested roles and transactions. This is stronger than an unqualified marketing logo, but the test scope is crucial. Ask which pieces of our clinical requirement might be demonstrated in such exchange testing and which still depend on the local workflow.
