0–7 · Useful delegation

  • Most-used tool paradox: computers are everywhere in practice, yet clinicians still manually move information between them.
  • Sharing and retaining work: changing software should not mean losing reusable records or asking patients to register again.
  • AI and research reuse: repeated collection and conversion make existing clinical work hard to use for another purpose.
  • Workarounds: photographing a screen, retyping and converting data bridge gaps but add manual steps; they are not the goal.
  • Databases and storage: databases organize related information; storage keeps the underlying files and records available.
  • Interfaces: people use screens; software exchanges files or uses an application programming interface (API) to request data or actions.
  • Clinical informatics: patients, clinicians and connected systems form a workflow; one application's screen is not the whole clinical network.
  • Bridge: ask what residents would want ready before the next visit, before asking how a tool obtains it.
