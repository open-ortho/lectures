15–27 · Make context reusable

Read the diagram from the source outward. The access-enforcing service checks credentials and requested scope before releasing records. The harness and model prepare a draft, not an authoritative chart entry. The clinician checks sources, missing information, contradictions and uncertainty before accepting or editing it. If a future workflow permits writeback, a separately authorized operation must place the reviewed result in the correct patient and encounter and preserve its provenance. No such clinical operation is being run in this lecture. Start with read-only retrieval so an evaluation does not silently change records. Audit records should let an operator establish who requested which information and what was changed. Neither a model's good intentions nor the word MCP replaces those controls. Ask what permission is unnecessary if the only approved task is preparing a read-only brief.
