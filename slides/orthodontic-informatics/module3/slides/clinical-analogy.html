15–27 · Make context reusable

Say the transition explicitly: This is my experience with email tools. The following clinical example is a proposed teaching scenario, not an integration I have deployed. An application programming interface, or API, lets software request data or actions from other software. Compare copying screenshots and typing values again with product B requesting permitted records directly from product A. If a second consuming product C is added, its identity and permissions must be configured independently; it should not borrow B's broad access or the clinician's login. Direct exchange can avoid some re-entry, but an API alone does not ensure correct identity, matching meaning or appropriate clinical use. Ask what would happen if the requested image were correct but belonged to another visit. This takes us from the connection to the context that must travel with it.
