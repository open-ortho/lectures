From clinical need to shared rules

  1. Clinicians describe the use case and failure conditions.
  2. Standards experts check what existing rules cover—and where gaps remain.
  3. Teams develop corrections, profiles or implementation guidance.
  4. Implementers test, report problems and refine the agreement.

DICOM, HL7 and IHE are communities to engage—not dates to memorize.

39–49 · Shape and test exchange

Explain standards development as an iterative path rather than a single universal sequence. Functional requirements can be captured in a functional profile or other use-case document, depending on the community. Gap analysis asks whether an existing standard and its guidance already support the need. A missing capability may need a correction or extension; ambiguity may instead require clearer implementation guidance. IHE, Integrating the Healthcare Enterprise, develops profiles for coordinated use of existing standards in defined workflows. The details vary across organizations, so do not claim that attending one event makes a draft become an established standard.
