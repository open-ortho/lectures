How does the model reach a tool?

Model ↔ harness ↔ selected email tools ↔ email service

Harness
The surrounding software that connects the model to tools and manages their interaction.
Model Context Protocol (MCP)
A common protocol through which servers expose tools to the harness.

A tool connection does not supply clinical meaning or grant permission by itself.

7–15 · Who is adapting?

Describe the harness as the surrounding application, not another model: it passes available tool descriptions to the model, handles requests, obtains results and continues the interaction. In this story, filtered and modified MCP servers expose selected email operations. A server here is software providing the operations; it need not mean a separate physical machine. MCP standardizes how tools and their results can be presented to the AI application. It does not define an orthodontic diagnosis, reconcile patient identity or authorize access just because a tool exists. The arrow is conceptual: details such as MCP clients inside the harness are not needed for today's judgment. Ask a resident to point to what actually stores the draft: the email service, reached through a tool, rather than the model's prose alone.
