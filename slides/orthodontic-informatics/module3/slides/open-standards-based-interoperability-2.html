A profile narrows choices in a standard for a particular use; an implementation guide brings together agreed usage, profiles, examples and other implementation rules. The exact meaning of profile differs between standards communities, so avoid suggesting every profile is a FHIR artifact. Terminology supplies agreed codes and meanings. A sender and receiver can both claim the same base standard while differing in required fields, terminology bindings or supported operations. A version is necessary information, not sufficient evidence. For T-017, a useful question is whether both products preserve the measurement unit, encounter link and original source document under the same agreed rules. Ask residents to turn supports FHIR into a more specific question. Source for FHIR profiling and implementation guides: https://hl7.org/fhir/profiling.html
