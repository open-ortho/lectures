Use one row at a time. Documentation must describe what the receiving implementation actually understands, not just advertise an interface. Maintenance needs a named owner regardless of whether the contract is private or shared. Shared specifications can reduce bespoke translation and permit reuse of tools, but unsupported fields, mismatched versions or local extensions can still require work. Vendor-specific integration can be appropriate when it meets a needed workflow and has a supportable contract. Neither public documentation nor standards branding proves total cost. Ask who will notice if an upgrade drops the source link while leaving the summary readable. A regression test of the actual case should catch that on either path.
