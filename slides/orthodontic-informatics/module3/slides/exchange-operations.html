A file download, a live connection and a saved clinical result prove different things.

15–27 · Make context reusable

  • Export: a portable copy with records and context another product can interpret; a download button alone does not demonstrate that.
  • Authorized retrieval: a permitted request returns only allowed records and their context; a live connection proves neither completeness nor permission to save results.
  • Return a result: deliver a reviewable draft linked to patient, visit and sources, with omissions and uncertainty visible.
  • Saving is separate: a chat answer is not a clinical chart entry; returning a draft does not establish authorized writeback (saving into the record).
  • Different evidence: download tests portability, retrieval tests permitted access, and a saved result tests placement and review controls; none proves the others.
  • Practical goal: avoid repeated manual assembly, not memorize categories; exported copies still need appropriate access and handling controls.
