15–27 · Make context reusable

What must the software make available?

CapabilityObservable output
ExportA portable record another system can interpret
Authorized retrievalOnly the permitted records and their context
Return a resultA reviewable draft linked to patient, visit and sources

A file download, a live connection and a saved clinical result prove different things.

These are supporting capabilities, not categories residents need to memorize as the purpose of the lecture. Ask what would let another authorized tool reuse this case without a clinician collecting, reformatting and explaining it again. An export must carry the included records and enough information for another product to interpret them; a download button alone is weak evidence. Authorized retrieval uses an interface under limited credentials; it does not imply a complete export or permission to store a result. Returning a chat answer does not mean it has been saved in the correct clinical record. For a result to be reviewable it needs its source links, patient and encounter associations, omissions and uncertainty. Exported copies also need appropriate access and handling controls.
