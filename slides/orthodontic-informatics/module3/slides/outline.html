0–7 · Useful delegation

  • Before the agenda: briefly recall Modules 1–2 as prerequisites, not another new topic.
  • Delegate to AI: choose useful clinical tasks, then identify the records each would require.
  • How I use AI: my actual email workflow contrasts manual copying with tools that read and save drafts.
  • Reusable context: carry patient, visit and source information; limit access and require clinical review.
  • Integration comparison: compare vendor-specific interfaces with shared standards for the same exchange—not APIs versus standards.
  • Requirements and Connectathons: clinicians specify observable outcomes; supervised exchanges test selected parts with other systems.
  • Exercise and Module 4: repair a synthetic proposal, summarize requirements, then ask vendors to demonstrate evidence.
