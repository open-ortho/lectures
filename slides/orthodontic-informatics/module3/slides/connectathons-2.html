39–49 · Shape and test exchange

  • Vendor support: profiles guide implementation; test tools and Connectathons help vendors check and improve exchange. Available support does not replace product-specific development or guarantee interoperability.
  • Two public sources: Connectathon results record tested capabilities; Product Registry Integration Statements are vendor-authored descriptions of supported capabilities, not independent test results.
  • Agent lookup: give the exact vendor, product and version; request supported versus tested capabilities, version matches, document/test dates, citations and explicit unknowns—not one implementation score. This is a suggested task, not a completed vendor investigation.
  • Interpret gaps: an absent entry or unavailable site does not prove no interoperability; ask the vendor and check the intended local exchange. A published test covers its stated scope, not the whole product.
