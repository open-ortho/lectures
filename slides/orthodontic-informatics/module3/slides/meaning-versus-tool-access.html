Reconnect the email story to the clinical analogy without claiming that installing MCP connects a chart safely. A selected tool could retrieve a clinical document using an underlying API, but the record's meaning still depends on its clinical contract. The harness manages the model-tool interaction; MCP can expose operations in a common way; neither determines that a diagnosis code, measurement or encounter link is clinically appropriate. The service receiving the request enforces permissions for the consuming identity. Present these as different jobs that may coexist, not three interchangeable technologies. Ask what remains missing if a tool returns a number successfully but drops its unit. The transport and invocation worked; the exchange did not retain enough meaning for the clinical task. That failure is something clinicians can help specify and test.
